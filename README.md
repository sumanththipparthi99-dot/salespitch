Built for **CredenceSoft BDM Interview** to showcase:
- Deep hospitality operations understanding

## 🚀 Quick Start

### **Option 1: GitHub Pages (Free)**

```bash
# Clone this repo
git clone https://github.com/yourusername/credencesoft-bdm-pitch.git
cd credencesoft-bdm-pitch

# File is already named index.html
# Push to GitHub and enable Pages in settings
git push origin main

# Live at: https://yourusername.github.io/credencesoft-bdm-pitch
```

### **Option 2: Vercel (Recommended)**

```bash
# Install Vercel CLI
npm install -g vercel

# Deploy
vercel --prod

# Live URL generated automatically
```

### **Option 3: Local Testing**

```bash
# Python 3
python3 -m http.server 8000
# Visit: http://localhost:8000

# Or just open in browser:
open index.html
```
